ChannelFFT (channel_handle, bank)

Parameters

channel_handle = channel returned by PlaySound, Play3DSound or PlayMusic, or 0 for the final mix
bank = bank to receive the spectrum, 256 floats = 1024 bytes

Description

Writes the current frequency spectrum of a channel into a bank, for example for a music visualizer. Up to 256 float values are written (fewer if the bank is smaller), read them with PeekFloat(bank, index * 4). Index 0 is the lowest frequency, index i covers roughly i * samplerate / 512 Hz. The values are unscaled magnitudes (the same as SoLoud's calcFFT), scale them to taste.

For a channel the spectrum is taken from the sound itself, before ChannelVolume/ChannelPan are applied, so it also works for a channel playing at volume 0. With channel_handle 0 the spectrum of the final audio output is returned (after all volumes, so silence gives 0 values; the first call after program start returns 0 values).

Returns the number of values written, or 0 if the channel is not playing (anymore), in which case the bank is filled with zeros.

Example

music = PlayMusic("music.ogg", True)
fft = CreateBank(256 * 4)
Print "Length: " + ChannelLength(music) + " seconds"
SeekChannel music, 30
While ChannelPlaying(music) And Not KeyHit(1)
ChannelFFT music, fft
Print ChannelPosition(music) + "s, bass: " + PeekFloat(fft, 4)
Delay 100
Wend
