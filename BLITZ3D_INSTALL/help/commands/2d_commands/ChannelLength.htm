ChannelLength# (channel_handle)

Parameters

channel_handle = channel returned by PlaySound, Play3DSound or PlayMusic

Description

Returns the length in seconds of the sound or music file that is playing on the channel.

Returns 0 if the channel is not playing (anymore).

Example

music = PlayMusic("music.ogg", True)
fft = CreateBank(256 * 4)
Print "Length: " + ChannelLength(music) + " seconds"
SeekChannel music, 30
While ChannelPlaying(music) And Not KeyHit(1)
ChannelFFT music, fft
Print ChannelPosition(music) + "s, bass: " + PeekFloat(fft, 4)
Delay 100
Wend
