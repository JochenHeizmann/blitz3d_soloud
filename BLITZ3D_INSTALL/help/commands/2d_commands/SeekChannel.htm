SeekChannel (channel_handle, seconds#)

Parameters

channel_handle = channel returned by PlaySound, Play3DSound or PlayMusic
seconds# = new play position in seconds

Description

Jumps to a new play position. The position is clamped to the length of the sound. Seeking in streamed OGG music is fast, other formats may have to decode up to the new position.

Returns 1 on success, 0 if the channel is not playing (anymore).

Example

music = PlayMusic("music.ogg", True)
fft = CreateBank(256 * 4)
Print "Length: " + ChannelLength(music) + " seconds"
SeekChannel music, 30
While ChannelPlaying(music) And Not KeyHit(1)
ChannelFFT music, fft
Print ChannelPosition(music) + "s, bass: " + PeekFloat(fft, 4)
Delay 100
Wend
