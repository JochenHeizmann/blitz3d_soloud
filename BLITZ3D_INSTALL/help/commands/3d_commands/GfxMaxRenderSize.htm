GfxMaxRenderSize()

Parameters

None.

Description

Returns the largest width and height (in pixels) that Graphics3D can use.

Direct3D 7 normally refuses back buffers above 2048 pixels ("Unable to create 3D Scene"). The runtime lifts this limit automatically at startup (in memory, for the running program only, no system files are changed). If that worked, GfxMaxRenderSize returns the largest texture size of the graphics card (for example 16384, or 8192 if the driver does not report one), otherwise 2048.

Example

; wanted size, for example the desktop size of an ultrawide monitor
w = 5120 : h = 1440
If w > GfxMaxRenderSize() Or h > GfxMaxRenderSize() Then w = 1920 : h = 1080
Graphics3D w, h, 32, 2
